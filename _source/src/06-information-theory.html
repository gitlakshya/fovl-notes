In 30 seconds

  • Entropy H(X): average surprise of one variable. Fair 8-sided die = 3 bits, fair coin = 1 bit.
  • Joint entropy H(X,Y): information needed to describe both together.
  • Conditional entropy H(Y|X): uncertainty left in Y once you know X. Language modelling is built on this.
  • Chain rule: H(X,Y) = H(X) + H(Y|X), extendable to whole sentences.
  • Mutual information I(X;Y) = H(X) − H(X|Y): how much knowing one tells you about the other. It's 0 if they're independent. It finds collocations like New Delhi.
  • KL divergence D(P‖Q): bits wasted by using the wrong distribution Q when the truth is P.

Warm-up: computing entropy

H(X) = − Σ p(x) log₂ p(x)
Worked example 1: a fair 8-sided die

8 outcomes, each with p = 1/8.

H = − 8 × (1/8) × log₂(1/8) = − log₂(1/8) = log₂ 8 = 3 bits

Meaning: a 3-digit binary code (000…111) is the shortest message that can report every roll.

Worked example 2: a fair coin
H = − [½ log₂ ½ + ½ log₂ ½] = 1 bit

One bit (0 = heads, 1 = tails) is enough.

Worked example 3: a biased coin (90% heads)
H = − [0.9 log₂ 0.9 + 0.1 log₂ 0.1] ≈ 0.9(0.152) + 0.1(3.322) ≈ 0.469 bits

Less than 1 bit, because the outcome is fairly predictable.

Note that for the die and the coin we never talk about history. Each roll is on its own. Language, though, depends on history ("a small oblong reading lamp on the…"). So we need entropies that take context into account.

Joint entropy H(X, Y)

The average information needed to specify both values together, e.g. the word pair New + Delhi as a unit.

H(X, Y) = − Σx Σy p(x, y) log₂ p(x, y)

Conditional entropy H(Y | X): the heart of language modelling

How much extra information, on average, you still need to communicate Y when you already know X.

Analogy: weather and umbrella

X = the weather, Y = "do I carry an umbrella?". If you don't know the weather, you're unsure. Once you know it's raining, you're almost certain. Knowing X reduced the uncertainty in Y.

Building the formula. For each possible value x, compute the entropy of Y in that situation, H(Y | X = x). Then take the weighted average, weighting by how often each x happens:

H(Y|X) = Σx p(x) · H(Y | X = x)

Expand H(Y | X = x) = − Σy p(y|x) log₂ p(y|x), then use p(x)·p(y|x) = p(x, y):

H(Y|X) = − Σx Σy p(x) p(y|x) log₂ p(y|x) = − Σx,y p(x, y) log₂ p(y | x)

Common mistake (made in class too): writing p(y|x) in front instead of p(x,y). The weights must be the joint probabilities.

Worked example: umbrella numbers

Weather: P(sunny) = 0.5, P(rain) = 0.5.
If sunny: P(umbrella) = 0.1. If rainy: P(umbrella) = 0.9.

  1. H(Y | sunny) = −[0.1 log₂0.1 + 0.9 log₂0.9] ≈ 0.469 bits
  2. H(Y | rain) = −[0.9 log₂0.9 + 0.1 log₂0.1] ≈ 0.469 bits
  3. H(Y | X) = 0.5 × 0.469 + 0.5 × 0.469 = 0.469 bits
  4. Without knowing the weather: P(umbrella) = 0.5×0.1 + 0.5×0.9 = 0.5, so H(Y) = 1 bit.

Knowing the weather cut the uncertainty from 1 bit to 0.469 bits.

The chain rule

Just as probability factorises, p(x, y) = p(x) · p(y | x), so does entropy:

H(X, Y) = H(X) + H(Y | X)    (and symmetrically = H(Y) + H(X | Y))
Derivation (step by step)

H(X,Y) = −E[log₂ p(X,Y)] = −E[log₂ (p(X)·p(Y|X))] = −E[log₂ p(X)] − E[log₂ p(Y|X)] = H(X) + H(Y|X).
(Uses log(ab) = log a + log b: products become sums.)

In words: the information needed for X and Y together = the information for X + the extra information for Y once X is known.

For a whole sentence of n words:

H(X₁, …, Xₙ) = H(X₁) + H(X₂|X₁) + H(X₃|X₁,X₂) + … + H(Xₙ|X₁…Xₙ₋₁)
Example

"John went to Patna": X₁ = John, X₂ = went, X₃ = to, X₄ = Patna. The joint entropy of the sentence is the sum of each word's entropy given all the previous words. This is exactly how language models score sentences (topic 07).

Umbrella check: H(X,Y) = H(X) + H(Y|X) = 1 + 0.469 = 1.469 bits.

Mutual information I(X; Y)

How much uncertainty about one variable disappears when you learn the other, i.e. how much information they share.

I(X; Y) = H(X) − H(X | Y) = H(Y) − H(Y | X)
I(X; Y) = Σx,y p(x, y) · log₂ [ p(x, y) / (p(x) · p(y)) ]
Worked example: umbrella again

I(weather; umbrella) = H(Y) − H(Y|X) = 1 − 0.469 = 0.531 bits. Knowing the weather tells you about half a bit about the umbrella.

If X and Y are independent

Then p(x, y) = p(x)·p(y), so the ratio inside the log is 1 and log 1 = 0. I(X;Y) = 0: neither tells you anything about the other.

Example: studying and passing

X = did the student study, Y = did the student pass. If they're unrelated, MI = 0. If almost everyone who passed studied and almost everyone who failed didn't, then seeing Y tells you a lot about X, and MI is high.

Example: language, "New ___"

Seeing New greatly increases the probability of Delhi: P(Delhi | New) ≫ P(Delhi). The choices shrink, so entropy drops, so New and Delhi share a lot of mutual information.

Collocations vs ordinary associations: "New car" and "new dress" are ordinary adjective + noun combinations. "New Delhi", "New York", "fast food" and "to-do" are collocations: fixed pairs that almost always appear together. In practice, the pointwise version, log₂[p(x,y)/(p(x)p(y))] for one specific pair, is used to find them.

Exam question flagged in class: prove MI is symmetric

Show I(X;Y) = I(Y;X).

Using the probability form: I(X;Y) = Σ p(x,y) log [p(x,y) / (p(x)p(y))]. Swapping X and Y changes nothing, because p(x,y) = p(y,x) and p(x)p(y) = p(y)p(x).

Using entropies: by the chain rule, H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y). Rearranging, H(X) − H(X|Y) = H(Y) − H(Y|X). The left side is I(X;Y) and the right side is I(Y;X). ∎

Practise writing this out by hand. It's easier said than done.

Relative entropy, a.k.a. KL divergence

Compares two probability distributions P and Q over the same set of events. (Comparing distributions over different event spaces is apples vs oranges.)

D(P ‖ Q) = Σx P(x) · log₂ [ P(x) / Q(x) ]

Meaning: the average number of bits wasted if events actually come from P but you use a code designed for Q.

Analogy: the wrong map

You plan a trip around Delhi using a New York traffic model. You'll take longer routes on average. The extra cost is the KL divergence. Likewise, a model trained on New York data may fit Indian data badly.

Worked example

True coin P = (0.5, 0.5). Your model Q = (0.9, 0.1).

D(P‖Q) = 0.5·log₂(0.5/0.9) + 0.5·log₂(0.5/0.1) ≈ 0.5(−0.848) + 0.5(2.322) ≈ 0.737 bits

If Q = P, the divergence is 0. KL is not symmetric: D(P‖Q) ≠ D(Q‖P) in general.

How do we evaluate any system?

Intrinsic evaluation

Measure against a ground truth with an internal metric: accuracy, entropy, perplexity, mutual information.

Extrinsic evaluation

Put it in a real task and compare with what humans do.

Exam tip

The professor said you may get derivation questions: conditional entropy (weighted average → joint form), the chain rule, MI symmetry. Also know: entropy of a die or coin, why entropy alone says nothing about sequences (use conditional entropy), and what KL measures.

Try it

A loaded 4-sided die has probabilities (½, ¼, ⅛, ⅛). Show H = 1.75 bits. (Hint: surprisals are 1, 2, 3, 3 bits.)

From the lecture slides

  • KL divergence has two equivalent forms on the slide: D(p‖q) = Σ p(x) log [p(x)/q(x)] = Ep[ log p(X)/q(X) ], i.e. the expected log-ratio under the true distribution p.
  • The conditional-entropy derivation slide ends with the identity p(x, y) = p(x) p(y|x), the one step that turns Σx p(x) Σy p(y|x) log p(y|x) into −Σ p(x,y) log p(y|x).
  • MI slide: "mutual information is literally the part of uncertainty that the two variables share" (the overlap of the Venn diagram). It's very useful for word associations and collocations.
  • The slide's summary: entropy → joint entropy → conditional entropy → chain rule → mutual information → relative entropy.

p(x,y) = p(x)p(y), so log[p(x,y)/(p(x)p(y))] = log 1 = 0, so I(X;Y) = 0.

C5. Prove I(X;Y) = I(Y;X) (assigned in class)

Chain rule both ways: H(X) + H(Y|X) = H(X,Y) = H(Y) + H(X|Y). Rearrange: H(X) − H(X|Y) = H(Y) − H(Y|X), i.e. I(X;Y) = I(Y;X). ∎

Practice Same level

P1. Joint table: p(0,0) = 0.4, p(0,1) = 0.1, p(1,0) = 0.1, p(1,1) = 0.4. Find H(X), H(Y), H(X,Y), H(Y|X) and I(X;Y).

Marginals are (0.5, 0.5) for both, so H(X) = H(Y) = 1 bit.
H(X,Y) = −[2·0.4 log₂0.4 + 2·0.1 log₂0.1] = 0.8(1.322) + 0.2(3.322) ≈ 1.722 bits.
H(Y|X) = H(X,Y) − H(X) ≈ 0.722. I = H(Y) − H(Y|X) ≈ 0.278 bits.

D(Q‖P) = 0.9 log₂(0.9/0.5) + 0.1 log₂(0.1/0.5) = 0.9(0.848) + 0.1(−2.322) ≈ 0.531 bits, while D(P‖Q) ≈ 0.737. Not equal.
