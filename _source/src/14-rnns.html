In 30 seconds

  • An RNN reads one word per time step and keeps a running memory, the hidden state ht, that mixes the new word with everything read so far.
  • The same weights are reused at every step, so it handles any length and the model size doesn't grow with input length.
  • Train with cross-entropy at every step and sum the losses. Teacher forcing feeds the gold words during training; at test time the model feeds its own outputs back in (autoregressive generation).
  • Uses: language modelling, sequence labelling (POS, NER with BIO tags), sequence classification (sentiment), encoder–decoder (translation).
  • Problems: vanishing/exploding gradients and no parallelism. Fixes: ReLU, careful initialisation, residual connections, gradient clipping, and LSTM/GRU gates.

The core idea: reuse one small network at every word

Analogy: reading with a running summary

When you read a novel, you don't reread every earlier page for each new word. You keep a mental summary and update it as you go. The RNN's hidden state is that running summary, and it uses the same "update rule" (the same weights) on every page.

The equations

e(t) = E · x(t)    (word embedding lookup)
h(t) = σ( Wh h(t−1) + We e(t) + b₁ )    (new memory = old memory + new word)
ŷ(t) = softmax( U h(t) + b₂ ) ∈ ℝ|V|    (probability of each next word)

You'll also see the names Wxh (input → hidden, = We), Whh (hidden → hidden, = Wh) and Why (hidden → output, = U). σ is often tanh.

Unrolling the first two steps

h(0) is an initial state (random or zeros).
t = 1: h(1) = σ(Wh h(0) + We e(1) + b₁)
t = 2: h(2) = σ(Wh h(1) + We e(2) + b₁). This contains h(1), which already contains word 1.
At t = 4, ŷ(4) = P(x(5) | the students opened their).

✔ Advantages

  • Processes any input length (just add time steps)
  • Step t can use information from many steps back
  • Model size doesn't grow with input length
  • Same weights at every step, so inputs are treated symmetrically

✘ Disadvantages

  • Computation is slow and sequential: step t must wait for step t−1
  • In practice it's hard to use information from many steps back (vanishing gradients)

Counting parameters (a favourite exam question)

Worked example 1 (slide exercise)

RNN language model, vocabulary {I, he, go, walk, eat} (one-hot size 5), hidden size 6, no biases. How many trainable weights?

Wxh: 5 × 6 = 30    Whh: 6 × 6 = 36    Why: 6 × 5 = 30    total = 96

A language model predicts the next word over the 5-word vocabulary, so the output layer counts. (Only the recurrence: 66.)

Worked example 2: an NER tagger

300-dimensional embeddings, hidden size 50, 5 entity types tagged with BIO.

Wxh: 300 × 50 = 15,000    Whh: 50 × 50 = 2,500

Output labels: B- and I- for each of the 5 types, plus O = 2n + 1 = 11. So Why: 50 × 11 = 550, total 18,050. (With 50 POS tags instead: 15,000 + 2,500 + 2,500 = 20,000.)

Rule of thumb: write out every weight matrix in the equations, give it a shape (rows × columns) that makes the multiplication work, multiply, and add.

Training an RNN language model

At each step, compare the predicted distribution ŷ(t) with the actual next word using cross-entropy:

J(t) = − log ŷ(t)[ x(t+1) ]     J = (1/T) Σt J(t)
Example

Input "the students opened their exams…": J(1) = −log P(students), J(2) = −log P(opened), J(3) = −log P(their), J(4) = −log P(exams). Add them up (this is also called the negative log-likelihood).

Teacher forcing vs inference

Teacher forcing (training)

At each step feed the gold previous word, even if the model predicted something else. If it said "home" instead of "students", we still feed "students" next. Otherwise one early mistake snowballs. The downside: the model may learn to reproduce training sentences too rigidly.

Inference (testing / generation)

Feed the model's own previous prediction back in. A mix of the two during training is also possible.

Computing the loss over a whole corpus at once is too expensive, so we use stochastic gradient descent on mini-batches.

Generating text (autoregressive generation)

  1. Start with a special start token <s>.
  2. Run forward, get a distribution, sample a word.
  3. Feed that word in as the next input.
  4. Repeat until </s> (end token) or a maximum length.
<s>→So→long→and→thanks→for→…→</s>

Sequence labelling: POS and NER

Same machinery, different gold outputs. Instead of predicting "students opened…", the target at each step is a tag:

Janet/NNP   will/MD   back/VB   the/DT   bill/NN

The tag for "bill" uses everything read before it through the hidden state.

NER with BIO tags

Entity types: PER (person), ORG, LOC, GPE, TIME, MONEY… Multi-word names need to know where an entity starts:

JaneVillanuevaofUnitedAirlinesHoldingdiscussedtheChicagoroute
B-PERI-PEROB-ORGI-ORGI-ORGOOB-LOCO

With n entity types the tag set has 2n + 1 labels. BIO turns span-finding into ordinary per-word labelling.

Bidirectional RNNs

For classification the whole sentence is available, so why only read left to right? Run one RNN forward and another backward, and concatenate their hidden states at each word.

Example: "The movie was terribly exciting!"

Reading left to right, "terribly" looks negative. The backward RNN has already seen "exciting!", so the combined representation knows "terribly" here means "very". (A 300-d forward state + a 300-d backward state = a 600-d representation.)

Evaluating LMs: perplexity again

perplexity = Πt ( 1 / PLM(x(t+1) | x(1..t)) )1/T = exp( J(θ) )the exponential of the cross-entropy loss. Lower is better.

Perplexity 1.44 means the model is choosing among about 1.44 words on average (confident). 4.07 means it's more confused.

Vanishing and exploding gradients

Back-propagation through time multiplies many derivatives together, one per step (chain rule through h(t) → h(t−1) → … → h(1)):

∂J/∂h(1) = ∂J/∂h(T) × ∂h(T)/∂h(T−1) × … × ∂h(2)/∂h(1)
Example

If every factor is about 0.5: 0.5¹⁰ ≈ 0.001, so the gradient vanishes and early words barely learn (the model "forgets" long-range context).
If every factor is about 2.5: 2.5¹⁰ ≈ 9,500, so the gradient explodes and training jumps wildly.

FixHow it helps
ReLU activationsGradient is 1 for positive inputs, so products don't shrink as much
Good weight initialisationStart where gradients are well-behaved
Residual connectionsPass the input forward unchanged as well, so information isn't lost if a layer changes little
Gradient clipping (for exploding gradients)If the gradient is too big, scale it down: g ← g · min(1, threshold / ‖g‖)
LSTM / GRUGates control what to remember and what to forget

LSTM and GRU: RNNs with gates

Analogy: a notebook with three rules

An LSTM keeps a notebook (the cell state ct). Each step it decides (1) what to erase (forget gate), (2) what new notes to write (input gate), and (3) what to read out loud right now (output gate). A sigmoid gate outputs values between 0 and 1: near 1 means "let it through", near 0 means "block it".

ft = σ(Wf[ht−1, xt] + bf)   it = σ(Wi[ht−1, xt] + bi)   ot = σ(Wo[ht−1, xt] + bo)
c̃t = tanh(Wc[ht−1, xt] + bc)    ct = ft ⊙ ct−1 + it ⊙ c̃t    ht = ot ⊙ tanh(ct)⊙ = element-wise multiplication

Example: when predicting x9, the information from x2 may no longer matter, and the forget gate learns to drop it. A GRU is a lighter version with two gates (reset and update). In the simple RNN a single line passes through tanh; the LSTM splits that same information into separate gated paths. (LSTMs were only covered briefly and won't be examined in detail.)

From the lecture slides

  • Named entities (anything referred to by a proper name). The 4 most common tags: PER ("Marie Curie"), LOC ("New York City"), ORG ("Stanford University"), GPE geo-political entity ("Boulder, Colorado"). The term is also extended to dates, times and prices.
  • Why NER? Sentiment toward a company or person, QA about an entity, information extraction. Why it's hard: (1) segmentation (find the span; POS tagging has none), (2) type ambiguity (is "Washington" a person, place or organisation?).
  • BIO tag count: 1 O tag + n B tags + n I tags = 2n + 1.
  • Cross-entropy properties (slide): converts multiplication into addition, strongly penalises confident wrong predictions, gives stable gradients, works well with softmax. Binary version: BCE = −[y log ŷ + (1 − y) log(1 − ŷ)].
  • SGD for RNN-LMs: computing loss over the whole corpus is too expensive, so treat x⁽¹⁾…x⁽ᵀ⁾ as a sentence or document and update per batch of sentences.
  • Vanishing gradient formula: ∂L/∂h₁ = (∂L/∂hn) Πl=1..n−1 ∂hl+1/∂hl. Solutions: ReLU, suitable initialisation, residual connections, LSTM/GRU. Solution 2: more direct, linear pass-through connections (attention, residuals).
  • LSTM vs RNN: if the forget gate says "remember everything", the cell barely changes, so information survives many steps. A plain RNN has to learn weights that preserve information on its own, which is very hard.
GRU equations (slide)
zt = σ(Wzxt + Uzht−1 + bz)  (update gate)    rt = σ(Wrxt + Urht−1 + br)  (reset gate)
h̃t = tanh(Whxt + Uh(rt ⊙ ht−1) + bh)    ht = (1 − zt) ⊙ ht−1 + zt ⊙ h̃t

Reset gate: how much past to forget (useful when the current input matters more). Update gate: how much new information replaces old memory.

C4. Cross-entropy (slide)

Gold [0, 1, 0, 0], predicted [0.1, 0.6, 0.2, 0.1]: −(0·log 0.1 + 1·log 0.6 + 0·log 0.2 + 0·log 0.1) = −log 0.6 ≈ 0.51.
Predicted [0.4, 0.3, 0.05, 0.25] where the true word got only 0.05: −log 0.05 ≈ 2.99. Confidently wrong predictions are punished hard.

C5. Vanishing gradient (slide)

1.44 means choosing among about 1.44 words (confident). 4.07 means "model confused, almost guessing among 4 words". Perplexity = exp(J(θ)).
