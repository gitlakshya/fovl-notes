09. Neural Network Basics

Lines, losses and gradient descent — the engine inside every modern NLP model.

Part B · Neural NLP🎙 Neural NLP Lecture 1 (10 Oct)

In 30 seconds

  • A neuron starts as linear regression: y = w·x + b. The weights tilt the line and the bias shifts it. Together they're the parameters.
  • Squash the output with a sigmoid to get a probability between 0 and 1 (logistic regression → classification).
  • A cost (loss) function measures the gap between predicted and gold values, e.g. (prediction − target)².
  • Gradient descent uses the slope to move the parameters downhill: w ← w − α · ∂C/∂w. The learning rate α sets the step size.
  • Non-linearities (sigmoid, tanh, ReLU) let networks fit curves, not just straight lines.
  • For text: tokenize → vocabulary → one-hot vectors → multiply by weight matrices. A neural network is mostly matrix multiplication.

Starting simple: pats and wags

You pat your dog and count how many times it wags its tail:

Pats (x)124
Wags (gold y)245

Can we predict the wags for a new number of pats? Linear regression fits a line:

wags = w × pats + b   (the familiar y = m x + c)
  • w (weight) controls the tilt (slope) of the line.
  • b (bias) moves the line up or down.
  • w and b are the model's parameters, and learning means finding good values for them.
Worked example: a bad first guess

Try w = 0.25, b = 0.68. Predictions: 0.93, 1.18, 1.68. Gold values: 2, 4, 5. Way off. The gap between the predicted and the gold (true) values tells us how bad the model is.

With two inputs (say flower length and width) the line becomes w₁x₁ + w₂x₂ + b, which is a plane.

From regression to classification: the sigmoid

Now the output is a label (red or blue flower). A linear model outputs any number from −∞ to +∞, and "12" or "−7" don't mean anything as probabilities. So we squash the output with the sigmoid:

σ(z) = 1 / (1 + e−z)    → always between 0 and 1
Example

σ(−2) ≈ 0.12, σ(0) = 0.5, σ(2.5) ≈ 0.92. Threshold at 0.5: an output of 0.92 means "very likely red", 0.12 means "very likely blue". This is logistic regression, the first classification model.

Measuring the error: the cost function

C = Σi ( predictioni − targeti )²   (sum of squared errors / MSE)

Why square? Without the square, positive and negative errors cancel and the value can run off to ±∞. Squaring keeps it positive and gives a nice bowl shape with one minimum.

A tiny network with no weights, only a bias

The network always predicts b, and the target is 4. Cost = (b − 4)². Obviously b = 4 is best. But with millions of parameters we can't just look at the formula and see the answer, so we need an algorithm that finds the minimum.

Gradient descent: walking downhill

Analogy: lost on a foggy hill

You're on a hillside in thick fog and want to reach the valley. You can't see the bottom, but you can feel which way the ground slopes under your feet. So you take a step downhill, feel again, and repeat. The slope (derivative) gives the direction, and the learning rate is your step size.

b ← b − α · dC/db    (and for every weight: w ← w − α · ∂C/∂w)
  • Slope > 0: decrease the parameter. Slope < 0: increase it. Slope = 0: you're at a minimum (for this bowl-shaped curve).
  • We subtract because the gradient points in the direction of steepest ascent, and we want descent.
Worked example: C = (b − 4)², start at b = 0, α = 0.1

dC/db = 2(b − 4).

The learning rate

Too small

Smooth but painfully slow, and you may run out of iterations before reaching the minimum.

Too large

Overshoots: jumps across the valley and can diverge. A common trick is a big rate early, then smaller as the loss settles.

More than one parameter

With both w and b, the cost is a 3-D bowl (a surface): one axis for w, one for b, height = cost. We use partial derivatives (∂C/∂w treating b as constant, ∂C/∂b treating w as constant) and step in both directions at once. Real cost surfaces have many local minima, and plain gradient descent can get stuck in one. Improved optimisers help with that.

Exam-style question (from the practice session)

Model ŷ = tanh(wx + b), loss L = (ŷ − y)². For the sample x = 1, y = 0.35, find ∂L/∂w.

Chain rule: ∂L/∂w = 2(ŷ − y) · ∂ŷ/∂w = 2(ŷ − y)(1 − ŷ²)·x, since d/dz tanh z = 1 − tanh²z.
With x = 1: ∂L/∂w = 2(tanh(w + b) − 0.35)(1 − tanh²(w + b)).

Follow-ups: if ∂L/∂w is negative, does w go up or down? Up (w − α·negative = w + something). Does a step along the negative gradient always reduce the cost? No. If the learning rate is too large you can overshoot.

Non-linearities (activation functions)

Without them, stacking layers still gives a straight line. With them, the model can bend to fit complex data.

ActivationOutput rangeTypical use
Step / threshold0 or 1historical perceptron
Sigmoid(0, 1)binary classification output
tanh(−1, 1)hidden layers, RNNs
ReLU = max(0, z)[0, ∞)default in deep networks
Softmaxprobabilities summing to 1choosing among many classes or words

Curves can underfit (too simple), overfit (memorises noise), or generalise (just right).

Neural networks for text: the hands-on part

Networks work on numbers, because they're equations. So text has to become numbers first.

  1. Data: a few sentences with labels, e.g. "I like computer science" → 1.
  2. Tokenize: split on spaces into tokens.
  3. Vocabulary: the list of unique words.
  4. Vectorize: one-hot / bag-of-words: mark 1 for every vocabulary word present in the sentence.
  5. Multiply by weight matrices to get scores, then compute the loss and update.
Worked example: one-hot sentence vectors

The class example: S1 = "New York Times", S2 = "Los Angeles Times".
Vocabulary (5): [New, York, Times, Los, Angeles].

A single word's one-hot vector has exactly one 1. A sentence vector marks every word it contains.

Matrix shapes

Example: 3 sentences, vocabulary 5, 2 output classes
H (3 × 5)  ×  W (5 × 2)  =  S (3 × 2)one row of 2 scores per sentence. Inner dimensions must match (5 = 5).

The weight matrix's first dimension matches the input size and its second matches the number of outputs. Weights start random and gradient descent updates them. Picking out a row of an embedding matrix for a word is called a lookup, and it becomes central in the next topic.

For classification with probabilities, squared error is a poor choice. We use cross-entropy loss instead (next topic).

Non-linearities, old and new

FunctionKey facts from the slides
Threshold unitOutputs 0 or 1, but has no gradient, so it can't learn
Logistic (sigmoid)Smooth, probabilistic. Problems: saturation, and outputs always positive (pushes activations upward)
tanhZero-centred, often converges faster. tanh(z) = 2·logistic(2z) − 1 (a rescaled sigmoid, twice as steep at 0, range [−1, 1]). Historically preferred in hidden layers
Hard tanhReplaces tanh's curved parts with straight lines, so no expensive exponentials
ReLU = max(z, 0)The first thing to try in deep networks: simple, strong gradients when active. Gradient for z < 0 is 0, so neurons can "die"
Leaky / Parametric ReLUAllow a small slope for negative inputs, which fixes dead neurons
Swish = z·logistic(z)Multiplies the input by a soft gate in (0, 1)
GELU = z·P(X ≤ z), X ~ N(0,1) ≈ z·logistic(1.702z)Scales z by how likely it is to be positive. Used in transformers (BERT, RoBERTa)
Why non-linearities are needed

A neural network is a function approximator. Without non-linearities, extra layers collapse into one: W₁W₂x = Wx. "Linear layers stretch and rotate space; non-linearities bend it." More non-linear layers mean more expressive power, but also harder optimisation and a risk of overfitting.

Teaching notes from the slides: "a neural network with no inputs (NN() = b) is not useful as a model of data; it's a teaching abstraction" for explaining cost functions. And: "Gradient descent does not find the minimum by knowing the answer, it finds it by following the slope." The cost surface over (w, b) was visualised in Wolfram Mathematica as a 3-D bowl: x-axis w, z-axis b, y-axis cost.

∂L/∂w = 2(tanh(w + b) − 0.35)(1 − tanh²(w + b)). A negative gradient means w increases. We subtract the gradient because it points to steepest ascent. A negative-gradient step doesn't always reduce cost (the learning rate can overshoot).

Practice Same level

P1. Predict the mystery flower (4.5, 1) with w₁ = 0.5, w₂ = 0.2, b = 0.3.

z = 0.5(4.5) + 0.2(1) + 0.3 = 2.75 → σ(2.75) ≈ 0.94, so red (class 1).

P2. Cost of w = 1.00, b = 1.50 on the pats data, and the gradient ∂C/∂b.

Errors (ŷ − y) = +0.5, −0.5, +0.5. Cost = 0.75. ∂C/∂b = Σ 2(ŷ − y) = 2(0.5 − 0.5 + 0.5) = 1.0, which is positive, so decrease b.

P3. One gradient step from w = 1, b = 1.37 (α = 0.01) on all three points.

Errors = 0.37, −0.63, 0.37. ∂C/∂w = Σ 2(e)x = 2(0.37·1 − 0.63·2 + 0.37·4) = 2(0.59) = 1.18. ∂C/∂b = 2(0.37 − 0.63 + 0.37) = 0.22. New w = 1 − 0.0118 = 0.988, b = 1.37 − 0.0022 = 1.368.

P4. Quiz model with w = 0.5, b = 0.1: compute ŷ, the gradient, and w after one step (α = 0.1).

ŷ = tanh(0.6) ≈ 0.537. Gradient = 2(0.187)(0.712) ≈ 0.266. w ≈ 0.473.
